## 2026-06-17

- Calibration: **landed the headline-calibration + favourite-longshot recalibration programme (calib-fl-05).** Applied the validated value gate set to `config.yaml` — `value.max_odds` **6.0 → 4.0** (CLV-first: the F-L recalibration flattens A/E across odds bands, so the cap is now driven by closing-line value, which is least-negative on the shortest-priced favourites), and rewrote the `max_odds` + probability-edge-gate comments (the edge gates are no longer "harmful" post-recalibration — they're CLV-neutral, so still off). Synced the stale code-default fallbacks that are documented to mirror config: `ValueConfig.max_odds` 6.0→4.0 + module docstring (`models/value.py`), `models/predictor._load_cfg` 26.0→4.0, `backtest/__main__` 26.0→4.0. `config.local.yaml` untouched. Regenerated `data/predictions.json` (111 races / 1223 runners): the headline `won_prob_normalized` is sane — mean 0.093, max 0.375, **no >0.70 saturation**, and sums to exactly 1.000 per race over the full field (the raw `won_prob` debug column still saturates at 0.734 by design). Re-ran `scripts.last_week_backtest`: headline calibration **ECE 0.222 → 0.029, AUC 0.773 → 0.778**; the value/top-pick strategies still lose **when settled at SP** (value EW −60% / win −72%; top-pick EW −25.5% / win −32.7%) — SP settlement is conservative and the real test is CLV, which (per calib-fl-04, 77k walk-forward frame) flattened A/E 2.80…0.17 → 0.94…0.78 and lifted yield +5.3%→+7.4% at the price taken but **stays negative (best ~−4%)**. README known-limits rewritten; tests updated for the new [2,4] band; `pytest -q` green. **Verdict: ranks well, headline calibrated, F-L bias fixed — but not yet proven bettable; paper-only.**

- Feature: **Yesterday's Bet Predictor** — an honest one-day backtest the user can run from the UI. New engine `models/yesterday.py` (`run_yesterday(YesterdayConfig)`): takes one _settled_ racing day, scores every runner **blind to the result** with the live models + the price-free v3nf value model, places bets (either the live value picks — same `models.value.find_value_bets` gating as Today's Suggestions — or the model's top win pick per race), settles win/each-way at the starting price, and reports staked / profit / ROI / win-rate. Loads the persisted `data/features/training.parquet` (instant). Because finishing positions lag the racing calendar by a few days (on 2026-06-17 the latest settled day was 2026-06-12; today/"yesterday" rows exist but with 0 positions), it **defaults to the most recent day that actually has results** and states the date + the SP-only/CLV-not-measurable caveat plainly. New Streamlit page `ui/pages/13_Yesterdays_Bet_Predictor.py` (strategy/bet-type/stake/settled-day controls, KPI rail, settled-bets table, honesty note). 13 unit tests in `tests/models/test_yesterday.py` (pure helpers + monkeypatched scoring for the end-to-end paths), all green. README updated: added the new page + Today's Suggestions to the UI table; corrected the stale "v3 uncalibrated" known-limit (v3 is now served calibrated per `model-11`; the `odds_finish` market-feature leak remains the reason to prefer v3nf); added a results-lag/SP-settlement limit. No existing modules changed — purely additive.
