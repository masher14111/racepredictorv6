## Repairs made this session
1. **Ledger cleanup**: released 2 orphaned reservations ($0.0057) left by the
   crashed process (no matching cache entry, no confirmed billing) before
   resuming — `data/cache/llm/hosted_budget_ledger.json`.
2. **Reasoning-budget bug (D47)**: uncontrolled hosted calls (no `reasoning`
   field, `max_output_tokens=800`) spent the ENTIRE completion budget on
   chain-of-thought on 176/243 real comments, returning no JSON at all
   (`schema_valid_rate` 27.57%). Added OpenRouter's `reasoning: {"effort":
   "low"}` (the model's lowest supported effort, per its live
   `supported_parameters`) and raised `max_output_tokens` to 1600 →
   `schema_valid_rate` 86.01%, cost/1000 comments DOWN from $0.78 to $0.37.
   Baseline reconstructed from the real cached responses at zero new spend:
   `reports/improvement/15/scorecard_hosted_reasoning_unset_baseline.json`.
3. **Cache-key bug**: `reasoning_effort`/`max_output_tokens` were not part of
   the hosted cache key — a rerun with a larger budget silently read back a
   stale exhaustion failure cached under the smaller one. Reproduced once
   (12-record test), then fixed; both are now in `_cache_key`.
4. **Actual-cost accuracy**: `extract()` now requests OpenRouter's own
   `usage.cost` (`"usage": {"include": true}`) and commits that to the ledger
   instead of a static price×tokens estimate, since this model's real price
   has weekday time-of-day tiers (2x peak/off-peak — see
   `openrouter_models_raw.json`) a fixed caller price can misprice on a
   different day. The worst-case RESERVATION still uses the caller-supplied
   ceiling price (fail-closed, unchanged; `PricingUnbounded` guard intact).
All 4 verified via `tests/llm/` (19 passed, no live calls) before any further
live call, then confirmed live on real data (below).

## Selection
No extractor is promoted or wired into production (`llm.enabled` stays
false, matching D12/D46) — this stage is a frozen-protocol comparison only,
per the prompt's own instruction that better extraction does not establish
better racing predictions. If forced to pick today: hosted recovers real
positives regex structurally misses, at much higher cost/latency and a
non-trivial residual schema-failure rate; regex is free, instant and fully
schema-valid but recall-blind on 3 of 6 features in this sample. Neither
local candidate could be measured.
