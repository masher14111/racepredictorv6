## New production code

- **`llm/shadow_extraction.py`** (new module) — reuses `OpenRouterBackend`, `HostedBudgetLedger`,
  `TextArchive`, and the existing `data/cache/llm` `Cache` unmodified; no competing client/ledger.
  - `ShadowExtractionStore`: new append-only `llm_shadow_extractions` table (migration 7, same
    `data/races.db`, same RAISE(ABORT) UPDATE/DELETE pattern as `text_archive`). Records source
    identity + original text hash (`archive_row_id`, `content_hash`, `source`), publication/
    acquisition time (`text_published_at`/`text_fetched_at`, copied from the archive row),
    **extraction availability time** (`extraction_time`, recorded separately and the ONLY field
    `as_of()` filters on — a late batch can never masquerade as pre-race data), schema/prompt/
    model versions, and grounded evidence (`features` JSON, same tri-state `FeatureValue` shape).
  - `verify_current_pricing()`: live-fetches OpenRouter's `/models` listing every run (cached
    fallback on transient failure; fails closed with neither), computes worst-case in/out price
    across time-of-day overrides, fails closed over the configured ceiling — same logic as
    `scripts/verify_hosted_pricing.py`, run fresh rather than from a frozen snapshot.
  - `run_shadow_extraction()`: bounded batch orchestrator. Fails closed (no ledger/network touch)
    on: disabled config, absent `OPENROUTER_API_KEY`, unverifiable/over-ceiling pricing. Selects
    unprocessed archived rows via one indexed SQL join (resumable dedupe, never loads the whole
    archive, never re-submits an already-recorded row), bounded to `batch_size_per_run`. Stops
    cleanly on `BudgetExceeded` mid-batch, preserving already-recorded progress for the next
    resume. `write_health_report()` persists a non-secret summary to
    `data/execution/shadow_extraction_health.json`.
- **`utils/storage/migrations.py`**: migration 7, additive.
- **`config.yaml`**: new `llm.hosted_shadow.*` section (`enabled: true`, model, reasoning_effort,
  max_output_tokens=1600, batch_size_per_run=25, price ceilings, shared $5/1200 caps) —
  independent of `llm.enabled`/`llm.backend`, which stay exactly as Stage 14 left them.
- **`scripts/refresh.py`**: two new best-effort steps in `_scrape()` — `_scrape_spotlight()`
  (calls the previously-unwired `scraper.spotlight.scrape()`) and `_shadow_extract_text()` (calls
  `run_shadow_extraction()` + `write_health_report()`), both wrapped exactly like the existing
  odds scrapers: logged and printed on failure, never raised, never blocking.
